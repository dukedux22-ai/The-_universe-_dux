❓ Help & Information

Everything you need to use ZYNOVA.

🧮 Calculator Help

Tap numbers and operators, then press =. Use sin, cos and tan in degrees. Memory buttons save a calculator value. History is stored locally.

🤖 AI Help

Ask complete questions such as “Explain momentum”, “Define a noun”, “Calculate 25% of 200”, or “Solve 3x + 4 = 19”. The offline engine recognizes many educational patterns.

🎮 Games Help

Choose a quiz category, start the quiz, select an answer and use Next Question. Correct answers increase your statistics and achievements.

💾 Backup Help

Backup creates a JSON file containing local ZYNOVA progress. Restore loads that file back into the app.

📱 PWA / Offline

The page is designed to work as a responsive web app. For full installable PWA caching, host the HTML from a web server or localhost; browsers normally restrict service workers on file:// pages.
